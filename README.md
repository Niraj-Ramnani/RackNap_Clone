# RackNap_Clone

A beginner-friendly, lightweight homepage recreation of the [RackNap](https://www.racknap.com/) website built using HTML5, CSS3, and vanilla JavaScript.

## Features
- **Header**: Clean navbar with logo, navigation links, and "Book a Demo" CTA button.
- **Hero Section**: Rating badge, bold typography with brand orange accent, description, action buttons, and dashboard hero image.
- **Trusted Worldwide Bar**: Industry reports citations and animated continuous ticker with partner logos.
- **Features Section (Dark)**: 4 segment cards with hover states, key performance metrics, and assessment CTA banner.
- **Footer**: 4-column layout with quick links, contact info, newsletter subscribe box, circular social icons, and copyright notice.

## Tech Stack
- HTML5
- CSS3 (Vanilla CSS, Responsive Grid & Flexbox)
- JavaScript (Minimal Vanilla JS)
